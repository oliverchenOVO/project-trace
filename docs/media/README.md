## 來源與判讀

截圖日期為 2026-10-04，來源為 Playwright 執行的 0.2.1 正式前端，搭配僅供測試的 IPC 轉接至同一套 Rust 核心。示範中的 Git 歷史、命令解析、測試程序與 bisect 均實際執行；這些圖不是設計稿。示範資料可透過 `npm run fixture` 重新建立，完整流程見 [SHOWCASE](../SHOWCASE.md)。截圖沿用原始影像，未重寫證據文字。

圖中的本機路徑與時間屬於截圖當時的驗證環境，不是安裝路徑要求。原始碼、提交訊息、命令與錯誤仍保留原文。架構圖是模組與資料流的概念說明，不是每個函式呼叫的完整時序圖；本機檔案產物與 SQLite 均在應用程式資料目錄保存。

## 放到個人網頁或推甄資料

- 優先用「證據圖譜」截圖作為專案封面，再用「回歸邊界」截圖解釋實驗成果。
- 架構圖可使用 SVG 保持清晰，Word 或簡報可使用 PNG。
- 沿用主 README 的圖說與「作品集摘要」，讓圖片有操作背景與技術說明。
- 截圖中的「回歸邊界已驗證」只表示所選測試與版本範圍內的結果，請勿改寫成「AI 已證明根本原因」。

GitHub README 已使用倉庫內的相對路徑。外部個人網頁可將所需圖檔複製到網站自己的素材目錄，避免依賴本機暫存路徑。
