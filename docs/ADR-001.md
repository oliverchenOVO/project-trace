# ADR 001: deterministic native core before AI

Accepted: 2026-10-04.

The native Rust core owns repository sessions, path validation, subprocesses, parsing, graph construction, SQLite and AI validation. React receives serializable evidence and cannot supply Git commands. Native commands run on blocking workers, separate from the renderer.

Snapshots retain source hashes, HEAD and porcelain status. Reopening compares all three and marks missing or changed evidence; a snapshot is never silently refreshed.

AI uses an optional local Ollama service at the fixed loopback endpoint. It receives a previewable, bounded, redacted evidence package and can return only a strict hypothesis object containing existing evidence IDs. No deterministic nodes or causal edges can be supplied by a model. AI unavailable is an explicit state, not an invitation to invent a result.

The showcase fixture is generated by a script with real commits and a real Node test failure; it is never auto-injected into application state.

Visual system: navy #0b1520, rail #0d1b28, panels #102130, muted #8fa7bb, cyan #4edcf0, amber #e6b55c, violet #b78aff, red #ff6578. Segoe UI body / Consolas evidence. Three columns, restrained 6px corners, dotted canvas, thin evidence borders. Literal epistemic labels accompany colors. Runtime screen starts empty until real evidence is collected; concept sample data is design-only.
